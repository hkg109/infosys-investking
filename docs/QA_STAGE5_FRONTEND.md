# QA 5단계 — 익명 실시간 순위 UI (F-11)

QA 4단계 PR #25가 병합된 최신 main `69be039`에서 시작했습니다. 기존 익명 순위 Backend 계약에 맞춘 Frontend 변경이며 서버·DB 스키마 변경은 없습니다.

## 변경 내용

- TOP 3와 접을 수 있는 전체 순위에 다른 참가자의 순위·총자산만 표시합니다. 닉네임·userId·현금·주식 평가액을 표시하지 않습니다.
- `isMe: true`인 본인 행만 ‘나’ 문구와 테두리로 강조합니다. 본인 자산 영역에는 본인 닉네임·순위·현금·주식 평가액을 표시합니다.
- 공동 3위까지 모두 표시하며 동점 이후 순위를 건너뛰는 서버 순위를 따릅니다.
- `rankings`, `top3`, `me` 간 참가자 수·동점 순위·본인 정보 일관성을 검증합니다. 응답에 불필요한 타인 식별 필드가 추가되어도 화면 상태에 보관하지 않습니다.
- 기존 Socket 알림·5초 조회·수동 재조회로 갱신하며 재접속/새로고침 후 인증된 API로 복구합니다.
- 최종 결과 확정 전과 확정 후를 구분합니다. `final: true` 응답만 최종 결과로 표시합니다.
- 세션 만료 시 이전 개인 결과를 즉시 지웁니다. 일시적 요청 실패는 같은 계정의 마지막 결과만 유지하며 오류 안내를 표시합니다.
