## 요약

정보 노출과 주문 동선을 개선하고, 매월 장중 사건 2~4개를 운영할 수 있도록 데이터와 검증을 추가합니다. 뉴스에는 사건 반영까지 남은 시간을 표시하며 예고 시 종소리를 세 번 재생합니다.

## 변경 사항

- 지난 정보는 보관함에서 회색의 작은 카드로 표시하고 읽기 동작을 차단
- 미구매 단서의 원제목·요약은 서버 응답부터 가리고 구매 후 전체 내용 제공
- 주문창에 기업 설명을 강조하고 시장에서 선택한 기업을 주문 기본값으로 전달
- 주문·보유·최근 거래에 기업명 표시, 차트 상세 기록 접기/펼치기 추가
- 장중 사건 18개 추가: 장중 36개 + 정규 마감 12개, 매월 장중 2~4개 배치
- 장중 사건의 마감 배정 방지, 초 단위 시간표와 30~80초 간격 검증
- 개별 사건 변동률 상한: 1~6월 ±30%, 7~12월 ±50% (월 누적 상한 아님)
- 단서 24개를 관련 사건에 연결하고 기말고사 보고서 공개 시점을 5월로 조정
- 메인·플로팅 뉴스 카운트다운, 일시정지 처리, 종소리 3회와 중복 재생 방지

## 검증

- 프론트엔드 테스트 109개 통과 및 프로덕션 빌드 성공
- PostgreSQL 격리 스키마 기반 백엔드 전체 테스트 61개 통과, skip 0
- 정보 비노출·만료, 등락률 경계, 사건 종류, 시간표, 카운트다운, 음소거 검증
- 실제 휴대폰 검수는 요청에 따라 제외
- 실브라우저 전체 동선과 실제 종소리 청취 검수는 미수행

## DB 적용

- 스키마 변경은 `npm --prefix server run db:migrate`로 적용
- 새 콘텐츠는 `node server/scripts/apply-qa37-39.mjs --dry-run` 검증 후 옵션 없이 적용
- 콘텐츠 스크립트는 로컬 DB의 WAITING/0월에서만 실행되며 먼저 백업 생성
- 사용자 승인 후 기존 게임을 백업·초기화하고 로컬 DB에 새 콘텐츠 적용 및 대조 완료
- 배포 서버에는 적용하지 않음
