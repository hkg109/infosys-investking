| 설정 | 값 |
| --- | ---: |
| 게임 ID | `00000000-0000-0000-0000-000000000001` |

| 한 달 전체 시간 | 120초 |

### 관리자 입력값

- 정규 사건: `trigger_phase=CLOSE`, `trigger_offset_ms=NULL`, `preannounce_ms=0`
- 장중 사건: `trigger_phase=INTRADAY`, `trigger_offset_ms=45000`, `preannounce_ms=10000`
- 같은 월의 장중 사건을 `display_order=1`, 마감 사건을 `display_order=2`로 저장
- 배정 모드는 `MANUAL`

## 8. 다른 컴퓨터로 옮기는 가장 안전한 방법

MD 표는 운영 확인용이고, 뉴스·결과·단서 전문과 UUID를 정확히 옮기려면 PostgreSQL 덤프를 함께 전달해야 한다. 비밀번호가 들어 있는 `.env`는 전달하지 않는다.

### 8.1 원본 컴퓨터에서 전체 DB 백업

PowerShell에서 프로젝트 루트로 이동한 뒤 실행한다. PostgreSQL 17 경로가 다르면 설치 버전에 맞게 바꾼다.

```powershell
cd C:\Users\junhu\OneDrive\Desktop\infosys-investking
$databaseUrl = (Get-Content .env | Where-Object { $_ -like 'DATABASE_URL=*' } | Select-Object -First 1).Substring(13)
& 'C:\Program Files\PostgreSQL\17\bin\pg_dump.exe' `
  --format=custom `
  --no-owner `
  --no-privileges `
  --dbname=$databaseUrl `
  --file='.\infosys-investking-event-day.dump'
```

생성되는 `infosys-investking-event-day.dump`에는 기업, 사건, 효과, 단서뿐 아니라 참가자와 진행 상태도 들어간다. 행사 전 빈 참가자로 넘길 경우 관리자 화면에서 게임 초기화를 한 다음 백업한다.

### 8.2 대상 컴퓨터 준비

```powershell
git clone https://github.com/hkg109/infosys-investking.git
cd infosys-investking
Copy-Item .env.example .env
```

대상 PC의 `.env`에서 `DATABASE_URL`을 그 PC의 PostgreSQL 계정과 DB에 맞게 수정한다. 비밀번호는 원본 PC와 같을 필요가 없다.

```powershell
cd server
npm install
npm run db:migrate
cd ..
```

### 8.3 대상 컴퓨터에서 복원

대상 DB는 비어 있는 새 DB를 권장한다. 기존 대상 DB를 덮어쓰는 작업이므로 DB 이름을 반드시 확인한 뒤 실행한다.

```powershell
cd C:\path\to\infosys-investking
$databaseUrl = (Get-Content .env | Where-Object { $_ -like 'DATABASE_URL=*' } | Select-Object -First 1).Substring(13)
& 'C:\Program Files\PostgreSQL\17\bin\pg_restore.exe' `
  --clean `
  --if-exists `
  --no-owner `
  --no-privileges `
  --dbname=$databaseUrl `
  '.\infosys-investking-event-day.dump'

cd server
npm run db:migrate
```

마지막 `db:migrate`는 최신 컬럼·제약조건을 보장하고 기존 `[장중]` 제목을 `[속보]`로 정규화한다.

## 9. 복원 확인 SQL

pgAdmin Query Tool에서 실행한다.

```sql
SELECT count(*) AS companies FROM companies;             -- 7
SELECT count(*) AS events FROM events;                   -- 30
SELECT count(*) AS effects FROM event_effects;           -- 113
SELECT count(*) AS clues FROM intelligence_clues;        -- 24
SELECT count(*) AS assignments FROM game_events;         -- 24

SELECT id, name, initial_price, current_price, is_active
FROM companies
ORDER BY id;

SELECT e.title,
       string_agg(ee.company_id || ' ' || ee.change_rate || '%', ', ' ORDER BY ee.company_id) AS effects
FROM events e
LEFT JOIN event_effects ee ON ee.event_id = e.id
GROUP BY e.id, e.title
ORDER BY e.title;

SELECT available_round, title, price, is_active
FROM intelligence_clues
ORDER BY available_round, created_at, id;

SELECT ge.round_number,
       ge.display_order,
       ge.trigger_phase,
       ge.trigger_offset_ms,
       ge.preannounce_ms,
       e.title
FROM game_events ge
JOIN events e ON e.id = ge.event_id
WHERE ge.game_id = '00000000-0000-0000-0000-000000000001'
ORDER BY ge.round_number, ge.display_order;
```
