# QA 31단계 — 관리자·시장 UI

## 완료 범위

- 관리자 참가자 표를 참가자, 접속, 현금, 주식 평가액, 총자산, 보유 종목, 관리 열로 재구성했다.
- 보유 종목을 펼치면 기업별 거래 상태, 수량, 현재가, 평가액을 확인할 수 있다.
- 실제 0원은 `0원`, 빈 보유 내역은 `보유 종목 없음`, API 실패는 오류 상태로 서로 구분한다.
- 모바일에서는 참가자 행을 핵심 자산 카드로 전환하고 보유 종목 상세만 가로 스크롤한다.
- 자산 수정 전 변경 필드와 수정 후 예상 총자산을 강조한다.
- `ASSET_CONFLICT`에서는 서버 최신 현금·수량을 보여주고 작성값을 자동으로 덮어쓰거나 재전송하지 않는다.
- 게임 진행 중, 오래된 데이터, 처리 중 요청 등 수정 불가 이유를 구체적으로 표시한다.
- 정보 카드의 화면 문구를 `정보 수정`, `정보 삭제`로 통일하고 실제 제목은 `aria-label`에 유지한다.
- 기업 설명 창을 고정 너비·내부 스크롤 구조로 정리하고 기업명, 업종, 설명, 현재가, 월 등락률을 분리했다.
- 기업 설명 창은 화면 경계를 보정하며 `×`, `Esc`, 외부 클릭으로 닫고 원래 기업 버튼으로 초점을 복원한다.
- 시장 API가 현재 월 시가 기준 `monthlyChangeRate`를 제공하며 시가 기록이 없으면 `null`을 반환한다.

## 검증 기준

- 참가자 자산 숫자, 0원, 빈 보유 종목, 비활성 종목 렌더링
- 자산 수정 예상 총자산과 게임 상태별 차단 이유
- 충돌 응답의 서버 최신값 표시 및 자동 재전송 방지
- 정보 수정·삭제의 화면 문구와 접근 가능한 이름
- 긴 기업 설명의 자동 줄바꿈·내부 스크롤과 데스크톱·모바일 경계 보정
- 시장 월 등락률 응답 계약과 기존 거래 흐름 회귀
