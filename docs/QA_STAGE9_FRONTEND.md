## 실행한 검증 (2026-09-18)

- `npm --prefix client test`: 68/68 통과. 신규 8개 테스트는 입력 범위, 응답 필드 검증, 본문 렌더링 분리·HTML 이스케이프, 구매 조건, 개인 캐시 제거, 인증/가격 요청, 응답 검증, POST 무재시도 검증.
- `npm --prefix client run build`: 성공.
- 개발 전용 `/test/intelligence.html` 모의 API에서 브라우저 검증:
  - 40P → 10P 구매 확인 → 30P·보관함 본문 → 새로고침 후 복구.
  - 0P 계정 전환: 포인트 부족, 이전 계정 본문 없음.
  - 세션 만료: 본문·잔액 캐시 제거.
  - 모의 구매 처리 후 응답 유실: GET 조회로 30P·보관함 복구.
  - 관리자 생성·가격 수정·비활성화·재활성화, RUNNING 상태 수정 차단.
  - 사용자·관리자 패널 너비 320/390/412/768px에서 가로 넘침 없음. 390px 사용자 화면 시각 확인.
  - 브라우저 콘솔 오류/경고 없음.

모의 데이터의 저장·차감은 테스트 화면에서만 흉내 냈습니다. 실제 DB Transaction, 서버 권한, 다중 기기 동시 구매, 실제 재접속 복구를 검증했다는 의미가 아닙니다. 실물 iPhone·삼성 테스트는 합의된 범위에서 제외합니다.
