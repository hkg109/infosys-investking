# QA 32단계 — 전체 종목 차트·통합 QA

## 완료 범위

- 로그인한 참가자가 `GET /api/trading/companies/history`로 모든 활성 기업 이력을 한 번에 조회한다.
- 전체 기업의 가격선을 같은 축에 표시하며 기업 코드별 색상과 선 패턴은 새로고침 후에도 유지된다.
- 차트 상단 범례는 색상, 기업 이름, 코드를 함께 제공한다.
- 기본 상태에서는 모든 선을 비교할 수 있고, 기업 선택 시 선택 선·점·이름만 강조한다.
- 같은 기업을 다시 누르면 전체 비교 상태로 돌아간다.
- 장중 사건 스냅샷은 해당 기업 선 위의 사건 마커와 접근 가능한 설명으로 표시한다.
- 모바일에서는 범례와 차트가 화면을 깨뜨리지 않고 가로 스크롤된다.

## 자동 검증

1. 전체 이력 API의 세션 인증, 활성 기업 7개, 코드 정렬, 공통 스냅샷 수를 검증한다.
2. 단일·전체 이력 응답의 숫자, 날짜, 사건 메타데이터와 중복 기업을 검증한다.
3. 기업별 고정 색상·선 패턴과 공유 가격 축을 검증한다.
4. 선택·비선택 선의 강조 상태, 기업명, 사건 제목을 정적 렌더링으로 검증한다.
5. 전체 Client/Server 테스트와 Client production build를 실행한다.

## 행사 기기 리허설

| 순서 | 화면 | 확인 항목 | 통과 기준 |
