# Frontend 12단계 — F-25~27

기준: 2026-09-23 origin/main `9766e3e` (11단계 PR #39 병합).
Backend API/DB 변경 없이 기존 기능을 작업별 nested route로 분리했다.

## URL 계약

| 영역 | URL | 내용 |
| --- | --- | --- |
| 관리자 | `/admin/overview` | 상태·시작·정지·재개·종료·초기화 |
| 관리자 | `/admin/participants` | 참가자 접속·자산 현황 |
| 관리자 | `/admin/companies` | 종목 관리 |
| 관리자 | `/admin/events` | 사건 및 월별 배정 |
| 관리자 | `/admin/missions` | 미션 관리 |
| 관리자 | `/admin/intelligence` | 단서 관리 |
| 관리자 | `/admin/results` | 이번 달 공개 결과 및 현재/확정 순위 |
| 참가자 | `/game/market` | 시장 종목·뉴스 |
| 참가자 | `/game/orders` | 보유 현황·매수·매도·결과 확인 |
| 참가자 | `/game/history` | 거래 내역·선택 종목 차트 |
| 참가자 | `/game/ranking` | 익명 순위·내 순위 |
| 참가자 | `/game/missions` | 미션·포인트·정보 구매 |
| 참가자 | `/game/profile` | 닉네임·복구 안내·로그아웃 |

`/admin`과 `/game`은 각각 overview/market으로 replace 이동한다. 인증되지 않은 참가자는
홈으로 이동한다. 관리자 하위 URL은 인증 전 내용을 마운트하지 않는다. 관리자 비밀번호는
메모리에만 유지하므로 같은 영역 메뉴 이동에는 유지되고 새로고침/영역 이탈 후 재인증한다.
배포 서버는 기존 SPA와 동일하게 하위 URL을 `index.html`로 fallback해야 한다.

## 상태·이동 보호

- 영역 부모에서 게임 Socket과 자산 상태를 유지한다. 하위 메뉴 이동으로 중복 생성하지 않는다.
- 현재 화면의 패널만 마운트하며 패널의 기존 요청 정리 함수를 그대로 사용한다.
- 종목·사건·배정·미션·단서 초안, 주문 입력, 초기화/구매 확인 중 메뉴 이동과 뒤로가기를 보호한다.
- 계속 작성하면 입력이 유지된다. 저장 또는 입력 취소 후 이동하거나, 초안을 버리고 이동할 수 있다.
- 처리 중인 요청은 결과를 기다려야 이동할 수 있다. 새로고침/탭 닫기는 브라우저의 이탈 확인을 사용한다.
- 불확실한 주문은 기존 서버/계정 복구 계약을 유지하고 이동만으로 재전송하지 않는다.
- 모바일 메뉴는 문서 안에서 가로 스크롤한다. 현재 메뉴에 `aria-current="page"`를 표시하고
  직접 진입 시 해당 메뉴를 스크롤 영역 안으로 보여준다. 화면 제목으로 키보드 포커스를 이동한다.
- 타이머는 기본적으로 본문에 배치해 메뉴를 가리지 않는다. ‘타이머 띄우기’로 기존 이동·크기 조절을 사용할 수 있다.
- 관리자/게임 코드는 lazy import로 분리한다.

## 검증

`npm --prefix client run qa:session`의 독립 PostgreSQL 스키마와 실제 API를 사용했다.

- 관리자 7개 메뉴 직접 URL 진입 → 재인증 → 해당 제목·메뉴 표시 확인.
- 관리자 메뉴 이동 중 재로그인 없음, 뒤로/앞으로 가기 URL·선택 메뉴 일치.
- 참가자 6개 URL 직접 진입 및 새로고침 후 세션·해당 화면 복구.
- 로그인 없이 `/game/history` 접근 시 홈으로 이동; `/admin/companies`는 인증 화면만 표시.
- 종목 초안 ‘보존할 초안’ → 다른 메뉴 이동 차단 → 계속 작성 시 유지 → 폐기 선택 후 이동.
- 주문 수량 2 입력 → 순위 이동 차단 → 계속 작성 → A 2주 실제 체결 → 내역 1건·20,000원 확인.
- 기존 체결 후 시장에서 B 선택 → 주문 메뉴에서도 B 유지. 주문 수량 3 입력 후 뒤로가기 차단·입력 보존.
- 입력 초기화 후에는 추가 경고 없이 순위로 이동.
- 관리자·참가자 320/390/768/1280px: 문서 폭이 뷰포트와 동일, 메뉴만 가로 스크롤.
- 참가자 타이머가 메뉴 아래에 배치되어 기본 상태에서 겹치지 않음.
- 정상 검증에서 브라우저 error/warn 없음.
- Frontend 자동 테스트 76개 통과(기존 74 + 메뉴/화면 분리 회귀 2), production 빌드 성공.

14단계 Hallmark 디자인 검수는 별도 범위다.
