# QA 6단계 Frontend — 게임·뉴스·플로팅 타이머 개편

## 구현 범위

- `F-12`: PC에서는 주문·자산·종목을 왼쪽, 뉴스·익명 순위를 오른쪽에 배치한다. 980px 미만에서는 게임 현황 → 자산/종목 → 주문 → 뉴스 → 순위의 한 열 흐름으로 전환한다.
- `F-13`: 뉴스를 기사 제목, 본문, 공개/예정 시각, 장중 속보 표시, 사건 결과와 영향 종목으로 구분한다. 적용 전인 사건은 결과와 변동률을 노출하지 않는다.
- `F-14`: 서버 기준 현재 월과 남은 시간을 고정 창에 표시한다. 마우스·터치 포인터로 이동하거나 오른쪽 아래 손잡이로 크기를 바꿀 수 있고, 위치 초기화 기능을 제공한다.

## 타이머 저장·복구 정책

- 타이머 위치와 크기만 브라우저 `localStorage`의 `investking:floating-timer:v1`에 저장한다.
- 게임 상태와 남은 시간은 저장하지 않고 항상 서버 응답을 사용한다.
- 저장값이 깨졌거나 저장소 접근이 차단되면 우측 상단 기본 위치로 복구한다.
- 브라우저 창이 작아지거나 회전해도 타이머가 화면 밖으로 나가지 않도록 위치와 크기를 다시 제한한다.
- 사용자별 금융 정보나 PIN은 브라우저 저장소에 기록하지 않는다.

## 자동 검증

```bash
cd client
npm test
npm run build
```

자동 테스트는 타이머 화면 경계·최소 크기·저장 복구, 서버 시간 표시, 미적용 사건 결과 비공개, 장중 속보와 상승·하락 종목 표시를 확인한다.

2026-09-18 기준 Frontend 테스트 46개가 모두 통과했고 Vite 배포 빌드도 통과했다. 실제 브라우저의 다중 사용자 흐름은 아래 확인 목록과 통합 QA에서 별도로 검증한다.

## 브라우저 확인 목록

- [ ] PC 1280px 이상에서 주문/자산이 왼쪽, 뉴스/순위가 오른쪽에 표시된다.
- [ ] 320px, 390px, 768px에서 모든 영역이 한 열로 표시되고 가로 스크롤이 생기지 않는다.
- [ ] 타이머를 네 모서리로 이동해도 일부가 화면 밖으로 숨지 않는다.
- [ ] 타이머 크기를 최소·최대로 조절한 뒤 새로고침해도 위치와 크기가 복구된다.
- [ ] `위치 초기화`를 누르면 타이머가 우측 상단으로 돌아간다.
- [ ] 게임 진행·일시정지·거래 마감·종료 때 타이머 상태 문구가 서버 상태와 일치한다.
- [ ] 장중 사건 적용 전에는 결과가 보이지 않고, 적용 후에는 결과·이전가·변경가·변동률이 표시된다.

실제 다중 참가자와 행사장 브라우저 검증은 모든 QA Frontend 단계가 병합된 뒤 통합 QA에서 수행한다.
