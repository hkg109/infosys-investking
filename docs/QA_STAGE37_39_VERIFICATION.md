# QA 37~39 구현·검증 기록

## 변경

- 만료 정보는 회색의 작은 카드로 표시하고 읽기 버튼·상세 열기를 제거한다. 이벤트 적용 상태를 서버에서 판정하며 종료된 게임의 정보도 지난 정보로 표시한다.
- 미구매 단서는 서버 응답부터 `비공개 … 보고서` 같은 표시 제목과 일반 안내 요약으로 대체한다. 구매 완료 후 원제목과 본문을 반환한다.
- 주문창 안에 기업 설명을 강조하고 시장에서 고른 기업을 주문 의도로 전달한다. 소비한 의도는 지워 탭 재진입 시 이전 주문창이 다시 열리지 않도록 했다.
- 주문 결과·미확정 주문·최근 거래 내역을 기업명으로 표시하고 보유 기업의 코드 태그를 제거했다. 차트 시가·종가 상세는 기본 접힘이다.
- 사건 종류를 DB에 보존한다. 분류된 장중 사건을 마감으로 배정하거나 종류를 바꾸는 요청을 거부한다. 기존 미분류 사건은 호환을 위해 null을 허용한다.
- 개별 사건 변동률은 1~6월 ±30%, 7~12월 ±50%다. 배정·배정된 사건 수정·게임 시작에서 검증한다. 월 누적 수익률 상한은 아니다.
- 장중 사건 18개를 추가해 총 36개와 정규 마감 사건 12개를 작성했다. 월별 장중 개수는 2,3,2,4,3,4,2,3,4,2,3,4다. 장중용 사건 2개를 마감에서 복원했다.
- 뉴스는 각 장중 사건 반영 30초 전 공개한다. 초 단위 시간표와 30~80초 사건·뉴스 간격을 검증한다. 모든 월에 2~4개를 배정해야 게임을 시작할 수 있다. 작성 중인 부분 배정 저장은 허용한다.
- 단서 24개를 관련 사건과 연결한다. 여러 사건을 설명하는 결제 보고서는 마지막 관련 사건에 연결해 너무 이른 만료를 막는다. 과거 사건이 대상이던 기말고사 보고서는 10월 공개에서 5월 공개로 옮겼다.
- 메인·플로팅 뉴스는 시계 시간 대신 사건 반영/거래 마감까지 남은 초를 표시한다. 일시정지에서는 멈추고 반영 후에는 완료 상태를 보여준다.
- 사건 예고음은 종소리 3회이며 음소거·사용자 오디오 활성화·동일 게임 알림 중복 방지를 적용했다.
