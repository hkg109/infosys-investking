# QA 3단계 — 종목 관리 UI (F-08)

새 `DEVELOPMENT_HANDOFF.md`의 재헌 3단계 범위입니다. 최신 `origin/main`의 2단계 PR #23 병합 커밋 `cdc61fa`에서 시작했습니다. 기존 종목 Backend API를 사용하며 DB migration이나 서버 계약 변경은 없습니다.

## 사용 방법

1. `/admin`에서 인증하고 **종목 목록 조회**를 누릅니다. 활성·비활성 종목을 모두 표시합니다.
2. 게임 대기 중 코드·이름·설명·초기 가격·활성 여부를 입력해 등록합니다. 소문자 코드는 대문자로 저장합니다.
3. 목록의 **수정**으로 이름·설명·가격을 바꿉니다. 코드는 변경할 수 없습니다. 초기 가격 변경은 현재 가격에도 반영됩니다.
4. **비활성화**를 누르면 최신 참조 수를 다시 조회합니다. 거래·보유·사건 기록 보존과 신규 사용 제한 안내에 동의한 뒤 확정합니다. 삭제하지 않고 비활성 상태로 유지합니다.
5. 비활성 종목은 **수정 → 활성 종목으로 사용 → 저장**으로 복구합니다.

## 오류·상태 처리

- 진행·일시정지·종료 상태에서는 조회만 허용합니다. 서버에서도 대기 상태를 검증합니다.
- 코드 형식, 이름 60자, 설명 2,000자, 제어 문자, 양의 안전 정수 가격을 API 계약에 맞게 검사합니다.
- 목록 조회 전, 게임 연결 오류 중, 작업 처리 중에는 변경을 막습니다.
- 저장 오류 시 입력을 보존합니다. 응답 유실·잘못된 성공 응답·서버 오류는 결과 불확실 상태로 취급하며 자동 재전송하지 않습니다. 목록을 다시 확인한 뒤 작업을 이어갑니다.
- 종목 변경 시 사건 관리 패널을 새로 열도록 갱신하여 예전 종목 목록을 사용하지 않게 합니다. 사건 입력 초안은 이때 초기화됩니다.
- 게임 초기화 완료 후 종목 목록을 다시 조회하도록 합니다.
