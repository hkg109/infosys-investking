# QA 11단계 Frontend — F-24

## 범위와 환경

2026-09-22~23, main `5c3e148` 기준으로 실제 Express·Socket.IO·PostgreSQL과
Vite 화면을 연결해 확인했다. 임시 PostgreSQL의 별도 스키마를 사용했으며 운영 데이터는
사용하지 않았다. 참가자 A는 Codex 내장 브라우저, 참가자 B는 Safari로 접속했다.
실물 iPhone/Samsung 테스트는 합의에 따라 제외한다. 반응형 검증은 브라우저 뷰포트
검증이며 실제 모바일 OS·프로젝터 검증을 대신 완료했다고 주장하지 않는다.

## 재현 방법

Node 22.12 이상, PostgreSQL 17과 별도의 테스트 DB가 필요하다.

```sh
npm --prefix server ci
npm --prefix client ci
TEST_DATABASE_URL=postgresql://USER:PASSWORD@127.0.0.1:5432/TEST_DB npm --prefix client run qa:session
```

- `http://127.0.0.1:4173/`: 참가자 화면. 두 번째 참가자는 별도 브라우저/프로필로 접속한다.
- `/admin`: 테스트 전용 비밀번호 `qa-ui-only`.
- `/broadcast`: 로그인 없는 공개 중계.
- 거래 5분 + 결과 30초, 1개월 게임을 준비한다. 시작 120초 후 A +10%, 마감 시 A -5%.
- 분산 보유 미션은 한 종목 매수로 10P를 지급하고, 단서는 5P로 구매할 수 있다.
- Ctrl+C로 종료하면 생성한 `ui_qa_*` 스키마만 정리한다. 강제 종료한 경우 해당 실행에서
  남긴 QA 스키마를 확인해 정리한다. 포트 4173이 사용 중이면 시작을 중단한다.

## 수정한 결함

중계의 고정 16:9 카드에서 7번째 종목이 아래쪽으로 잘리고 `overflow: hidden` 때문에
볼 수 없었다. 종목 행의 세로 간격을 줄여 기본 7종목이 들어가게 했다. 종목·동점 순위·
월 결과가 많으면 카드 내부를 스크롤할 수 있으며 키보드 포커스와 표시 테두리를 제공한다.

## 자동 검증

- Frontend `npm test`: 74개 통과, 실패/스킵 0.
- Frontend `npm run build`: production 빌드 성공.
- Backend `TEST_DATABASE_URL=... npm run test:integration`: 실제 DB 통합 회귀 48개 통과, 실패/스킵 0.
- `.github/workflows/frontend-qa.yml`: 이후 client PR에서 테스트·빌드를 자동 실행한다.

브라우저 검증은 위 관찰 시나리오에 한정된다. 장시간 부하·실제 행사망 장애·프로젝터 색상은
별도 운영 리허설 대상이며, 12~15단계 화면 분리·오버레이·디자인·최종 회귀 QA는 이번 범위가 아니다.

장중 예고의 짧은 전환 연출은 이번 실제 브라우저 관찰에서 포착하지 못했다.
예고·속보 전환 조건 및 중복 재생 방지는 기존 자동 테스트로 검증했으며, 실제 연출 관찰은 후속 회귀 QA에 남긴다.
